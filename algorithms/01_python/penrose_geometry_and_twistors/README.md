# Penrose Geometry, Spinors, and Twistor Theory

Algorithms and mathematical structures inspired by Roger Penrose's *The Road to Reality: A Complete Guide to the Laws of the Universe*.
Covers stereographic projection on the Riemann sphere, 2-spinor algebra, Infeld-van der Waerden symbols, twistor kinematics, Petrov classification, Weyl curvature decomposition, and optical scalars.
