# Modern Scientific C++20 Suite

High-performance numerical algorithms written in clean, modern C++20.
Includes self-contained header/implementation pairs with unit tests:
1. `cholesky_decomposition` - Cholesky $L L^T$ matrix factorization
2. `conjugate_gradient` - Iterative linear system solver
3. `gaussian_quadrature` - Gauss-Legendre quadrature
4. `spline_interpolation` - Natural cubic spline interpolation
5. `nelder_mead_simplex` - Multi-dimensional unconstrained simplex minimization
6. `rk45_dormand_prince` - Adaptive step-size Runge-Kutta ODE solver
7. `kdtree_spatial_index` - K-Dimensional binary search tree
8. `bloom_filter` - Probabilistic bitset membership filter
9. `b_spline_curve` - De Boor's B-spline curve evaluator
10. `qr_eigenvalues` - Francis QR algorithm for symmetric matrix eigensystems
