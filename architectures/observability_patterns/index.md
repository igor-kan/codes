# Observability Patterns

Understand a system's internal state from its outputs: logs, metrics, traces.

| Pattern | File | Idea |
|:---|:---|:---|
| Structured Logging | `logging.md` | machine-parseable events |
| Metrics | `metrics.md` | aggregates over time |
| Distributed Tracing | `tracing.md` | follow a request across services |
| Health Checks | `health_checks.md` | readiness/liveness |
| Correlation IDs | `correlation_ids.md` | stitch logs and traces |

Related: `devops/monitoring/`, SRE practices.
