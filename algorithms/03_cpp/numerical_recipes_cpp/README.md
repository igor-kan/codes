# Modern C++ Numerical Recipes Algorithms

High-performance C++20 header-only algorithms based on:
- **Press et al.**: *Numerical Recipes: The Art of Scientific Computing*
- **Bjarne Stroustrup**: *The C++ Programming Language*

Includes symplectic Verlet integrators, Cash-Karp Runge-Kutta, Thomas tridiagonal linear solvers, Brent's root-finding method, and Cooley-Tukey Radix-2 Fast Fourier Transforms with self-contained test suites.
