# Quantitative Finance & Econophysics

Quantitative trading and econophysics algorithms based on:
- **Marcos Lopez de Prado**: *Advances in Financial Machine Learning*
- **Marcos Lopez de Prado**: *Machine Learning for Asset Managers*
- **Jovanovic**: *Econophysics and Financial Economics*
- **Pal**: *Practical Time Series Analysis*

Features fractionally differentiated time series (FFD), triple barrier labeling, symmetric CUSUM filters, meta-labeling bet sizing, Hierarchical Risk Parity (HRP), Heston stochastic volatility simulation, Merton jump-diffusion, VPIN order flow toxicity, Ornstein-Uhlenbeck pairs trading calibration, Black-Scholes Greeks, Brent's method implied volatility solvers, Calmar ratios and maximum drawdowns, CEV models, SABR volatility smiles, and Nelson-Siegel yield curve parameterizations.
