# Mathematical Physics Algorithms & Special Functions

Implementations drawn directly from classical mathematical physics literature:
- **Arfken, Weber, Harris**: *Mathematical Methods for Physicists* (7th Ed.)
- **Mary L. Boas**: *Mathematical Methods in the Physical Sciences* (3rd Ed.)
- **Riley, Hobson, Bence**: *Mathematical Methods for Physics and Engineering* (3rd Ed.)
- **Mauch**: *Introduction to Applied Mathematics*

Contains robust implementations of Sturm-Liouville solvers, orthogonal polynomials, cylindrical Bessel functions, spherical harmonics, Hermite/Laguerre eigenstates, Chebyshev approximation, hypergeometric series, Gamma/Beta functions, conformal mappings, Kramers-Kronig relations, curvilinear differential operators, Hankel transforms, and Green's functions.
