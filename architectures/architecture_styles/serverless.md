# Serverless

Run code on managed platforms that scale to zero, billed per use (FaaS + managed
services).

## Benefits

- No server management; automatic scaling.
- Pay only for execution; fast time-to-market for events.

## Constraints

- Cold starts and execution time/memory limits.
- Statelessness; external state stores.
- Vendor lock-in and local testing friction.

Good for event processing, APIs with spiky traffic, and glue automation.

Related: FaaS, Event-Driven, Backends for Frontends.
