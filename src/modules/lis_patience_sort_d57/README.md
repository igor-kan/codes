# O(N log N) Patience-Pile Longest Increasing Subsequence (`lis_patience_sort_d57`)

> Category: **Sequence Dynamic Programming** | Language: **C++20**

## Overview

Tracks minimal tail elements per subsequence length via std::lower_bound binary updates to determine longest strictly increasing subsequence cardinality.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Increasing subsequence length satisfies 1 <= LIS <= N for non-empty inputs.
