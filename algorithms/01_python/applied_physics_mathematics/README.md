# Applied Physics & Mathematical Methods

Algorithms inspired by:
- Ya. B. Zeldovich, *Higher Mathematics for Beginners: Physicists and Engineers*
- George Polya, *Mathematical Methods in Science*

Covers multi-stage rocket equations, thermal explosions (Frank-Kamenetskii), Fermat ray tracing in gradient-index media, Buckingham Pi theorem, capillary rise, Rankine-Hugoniot shock relations, and isoperimetric variational optimization.
