# Asymptotic Methods & Perturbation Theory

Algorithms and solvers inspired by:
- Sean Mauch, *Introduction to Applied Mathematics*
- Tai L. Chow, *Mathematical Methods for Physicists*

Covers WKB semiclassical approximation, Poincaré-Lindstedt secular term elimination, matched asymptotic expansions, Watson's lemma, Stirling asymptotic series, Euler-Maclaurin summation, method of multiple scales, Airy & Bessel asymptotic series, and Pade approximants.
