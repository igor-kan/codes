# Manacher Linear Palindromic Radii Analyzer (`manacher_palindrome_radii`)

> Category: **String Algorithms** | Language: **C++20**

## Overview

Expands a sentinel-free index transformation in O(N) time to determine the longest palindromic substring length and center position.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Returned substring slice equals its character-by-character reversal.
