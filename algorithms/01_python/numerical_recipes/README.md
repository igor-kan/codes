# Numerical Recipes Algorithms

Algorithms and numerical methods adapted from standard scientific computing references:
- **Press, Teukolsky, Vetterling, Flannery**: *Numerical Recipes: The Art of Scientific Computing* (3rd Ed.)
- **Kincaid & Cheney**: *Numerical Analysis: Mathematics of Scientific Computing*
- **Schörghofer**: *Lessons in Scientific Computing*

Contains implementations of symplectic integrators, Bulirsch-Stoer extrapolation, adaptive RKF45, SVD pseudoinverses, Householder QR decomposition, Thomas tridiagonal solvers, Gauss-Legendre quadrature, Romberg integration, adaptive Simpson's quadrature, Newton-Raphson with line search, Broyden's method, Nelder-Mead simplex, BFGS optimization, conjugate gradient solvers, and cubic splines.
