# Computational Biology & Population Genetics

Algorithms inspired by Urry et al., *Campbell Biology (12th Edition)*.
Covers Hardy-Weinberg selection dynamics, Wright-Fisher stochastic drift, Kimura neutral molecular evolution, UPGMA and Neighbor-Joining phylogenetic reconstruction, Smith-Waterman local alignment, Needleman-Wunsch global alignment, Michaelis-Menten enzyme kinetics, Lotka-Volterra predator-prey dynamics, Kingman coalescent, and CpG island detection.
