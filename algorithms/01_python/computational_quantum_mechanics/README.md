# Computational Quantum Mechanics

Implementation of computational quantum mechanics algorithms based on:
- **Izaac & Wang**: *Computational Quantum Mechanics* (Springer)
- **Landau & Lifshitz**: *Quantum Mechanics: Non-Relativistic Theory* (Vol. 3)

Features Numerov bound state solvers, split-operator FFT evolution, transfer matrix tunneling, variational Rayleigh-Ritz eigensolvers, Hartree-Fock SCF for Helium, WKB approximations, bipartite entanglement and partial trace, coherent states, tight-binding models, Berry phase, partial wave scattering, 1D Kohn-Sham DFT, Aharonov-Bohm phase, Landau levels, and FDTD wavepacket scattering.
