# Financial Machine Learning & Quantitative Asset Management

Algorithms inspired by Marcos Lopez de Prado's *Advances in Financial Machine Learning* and *Machine Learning for Asset Managers*.
Covers triple barrier labeling, fractional differentiation, purged K-fold cross validation, CUSUM filtering, bet sizing, Hierarchical Risk Parity (HRP), entropy estimators, Almgren-Chriss optimal execution, Marcenko-Pastur covariance denoising, and Deflated Sharpe Ratio.
