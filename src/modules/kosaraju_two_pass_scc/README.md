# Kosaraju Two-Pass Strongly Connected Components & Condensation DAG (`kosaraju_two_pass_scc`)

> Category: **Graph Connectivity** | Language: **C++20**

## Overview

Computes all Strongly Connected Components via finish-time DFS on G followed by reverse finish-order DFS on transpose graph G^T, automatically emitting components in topological condensation DAG order.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(V + E)` |
| **Space Complexity** | `O(V + E)` |

## Mathematical & Safety Invariants

- Every vertex belongs to exactly one SCC id in [0, num_components - 1].
- All condensation DAG edges strictly point from lower component ID to higher component ID.
