# Functional Analysis & Advanced PDE Methods

Algorithms inspired by:
- Sadri Hassani, *Mathematical Methods for Physics*
- Mattias Blennow, *Mathematical Methods for Physics and Engineering*

Covers method of steepest descent / saddle point, Mellin transform, Riemann-Liouville fractional derivatives, 3D Helmholtz Green's function, Cauchy principal value integration, Kramers-Kronig dispersion, Sturm-Liouville eigensystems, and Chebyshev spectral differentiation.
