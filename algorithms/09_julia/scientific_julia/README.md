# Scientific Computing in Julia

Modern scientific algorithms implemented in Julia:
1. `spectral_fft_pde.jl` - Pseudospectral PDE wave dispersion
2. `autodiff_dual_numbers.jl` - Forward-mode dual number automatic differentiation
3. `symplectic_verlet.jl` - Symplectic velocity-Verlet celestial orbit integration
4. `simplex_linear_programming.jl` - Two-phase simplex method
5. `monte_carlo_ising.jl` - Metropolis-Hastings 2D Ising model
6. `gram_schmidt_qr.jl` - Modified Gram-Schmidt orthogonalization
7. `arnoldi_iteration.jl` - Krylov subspace Arnoldi iteration
8. `gaussian_elimination_pivot.jl` - Gaussian elimination with complete pivoting
9. `levenberg_marquardt.jl` - Non-linear least squares optimization
10. `fast_chebyshev_eval.jl` - Clenshaw recurrence evaluation
11. `singular_value_decomposition.jl` - Power iteration SVD
12. `random_walk_hitting_time.jl` - Markov chain hitting times
13. `navier_stokes_staggered_grid.jl` - Marker-and-cell pressure projection
14. `wavelet_haar_transform.jl` - 1D discrete Haar wavelet decomposition
15. `page_rank_power_method.jl` - PageRank power method
