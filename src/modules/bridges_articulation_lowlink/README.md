# Tarjan Low-Link Bridge & Articulation Point Graph Cut Finder (`bridges_articulation_lowlink`)

> Category: **Graph Algorithms** | Language: **C++20**

## Overview

Detects every cut-edge (bridge) and cut-vertex (articulation point) in undirected graphs with arbitrary disconnected components and parallel edges using discovery timestamps and low-link propagation.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(V + E)` |
| **Space Complexity** | `O(V + E)` |

## Mathematical & Safety Invariants

- Parallel multi-edges between identical endpoints are never misclassified as bridges.
- Removing any reported bridge strictly increases the number of connected components.
- Removing any reported articulation point from its component splits remaining vertices into >= 2 components.
