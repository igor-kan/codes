# Scientific C Algorithms Suite

Foundational C99/C11 numerical and computational algorithms inspired by:
- Brian W. Kernighan & Dennis M. Ritchie, *The C Programming Language (2nd Ed.)*
- Stephen G. Kochan, *Programming in C*

Includes self-contained header/implementation pairs with standalone unit tests:
1. `rk4_integrator` - 4th-order Runge-Kutta numerical ODE integration
2. `fast_fourier_transform` - In-place Cooley-Tukey radix-2 FFT
3. `matrix_inversion_lu` - LU decomposition with partial pivoting
4. `brent_root_finding` - Brent-Dekker hybrid root finding algorithm
5. `simpson_adaptive` - Adaptive recursive Simpson's rule quadrature
6. `quaternion_kinematics` - Unit quaternion 3D rotation and SLERP
7. `complex_arithmetic` - Complex transcendental operations
8. `polynomial_roots_laguerre` - Laguerre's polynomial root method
9. `sparse_matrix_csr` - Compressed Sparse Row (CSR) matrix-vector product
10. `monte_carlo_pi` - High-performance Monte Carlo integrator
11. `levenshtein_distance` - Dynamic programming Levenshtein string distance
12. `sha256_digest` - FIPS 180-4 SHA-256 cryptographic hash
13. `convex_hull_graham` - Graham scan 2D computational geometry convex hull
14. `huffman_coding` - Prefix code tree construction
15. `dijkstra_shortest_path` - Dijkstra algorithm on weighted adjacency graphs
