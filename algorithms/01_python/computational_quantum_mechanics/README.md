# Computational Quantum Mechanics

Algorithms for time-dependent Schrodinger equation (TDSE), split-step Fourier methods, infinite well, harmonic oscillator, Morse potential, tunneling, and density matrices (Izaac 2019, Landau Vol 3).

## Modules

- `bloch_electron_periodic.py`
- `delta_potential_well.py`
- `hartree_fock_two_electron.py`
- `infinite_square_well.py`
- `morse_potential_diatomic.py`
- `pauli_spin_matrices.py`
- `quantum_anharmonic_perturbation.py`
- `quantum_density_matrix.py`
- `quantum_harmonic_oscillator.py`
- `quantum_tunneling_barrier.py`
- `schrodinger_1d_fdtd.py`
- `split_step_fourier_qm.py`
- `stern_gerlach_filter.py`
- `variational_ground_state.py`
- `wigner_quasiprobability.py`
