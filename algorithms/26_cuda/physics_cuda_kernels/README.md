# High-Performance CUDA Physics Kernels

CUDA C/C++ parallel computing kernels for scientific simulation and physics:
- **CUDA C Best Practices & Programming Guide** (NVIDIA 2019)
- **Han**: *Learn CUDA Programming*

Features N-body direct gravitational interactions with EPS smoothing, 2D acoustic/elastic wave equation FDTD solvers, 3D unsteady heat conduction, checkerboard Monte Carlo 2D Ising model sweeps, warp-shuffle parallel sum reductions, and work-efficient Blelloch prefix-sum scans.
